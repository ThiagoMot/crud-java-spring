# API CRUD de Produtos - Spring Boot

API RESTful para gerenciamento e cadastro de produtos desenvolvida com Java, Spring Boot e banco de dados em memória H2.

---

## 🛠️ Tecnologias Utilizadas

* **Java 21**
* **Spring Boot 3**
* **Spring Data JPA**
* **H2 Database** (Banco de dados em memória)
* **Maven**

### Pré-requisitos
* Java 21 ou superior instalado
* Git instalado
